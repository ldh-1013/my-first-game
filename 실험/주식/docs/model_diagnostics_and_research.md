# Stock Insight 예측 성능 고도화 기록

## 측정 정의

- 예측 시점: 거래일 D 종가까지 확인 가능한 정보
- 목표: D 종가 대비 다음 실제 거래일(D+1) 종가 수익률의 방향
- 보합 처리: 실제 수익률 0%는 방향 적중률에서 제외하고 별도 집계
- 검증 분리: 학습 15개월, 확률 보정 3개월, 최종 시험 6개월
- 추가 검증: 월별 확장형 워크포워드
- 선택적 신호: 보정 구간에서 확률 기준을 선택한 후 최종 시험 구간에서만 평가
- 비용 가정: 선택 신호 왕복 거래비용 0.20%

## 시점 누수 방지

가격 특징은 예측일 이하의 일봉만 사용한다. 미래 가격, 실제 수익률, D+1 지표는
명시적 특징 목록에 들어갈 수 없다. 뉴스는 게시 시각과 수집 시각을 구분하지만,
과거 시점 보급률이 낮은 구간은 결측으로 처리한다. 재무 자료는 `as_of_date`가
예측일 이하인 표본만 허용하며, 정정 전 공시 이력이 보장되지 않는 자료는 제한으로
표시한다.

## 추가된 특징

- 5일·20일 수익률
- 5일·20일 이동평균 이격도
- ATR 비율과 20일 변동성
- 거래량 변화율, 로그 거래대금, 시장 내 유동성 백분위
- 시장 대비 5일 상대강도
- 시장 1일·20일 수익률, 상승 종목 비율, 시장 변동성
- 상승·하락·횡보와 고변동 조합의 시장 국면

현재 데이터베이스에는 신뢰할 수 있는 과거 투자자 수급과 종목별 섹터·산업 분류가
충분하지 않아 해당 특징은 구현 가능 목록에만 남겨 두고 값을 만들지 않았다.

## 후보 모델과 승격 기준

규칙형 기준 모델, 로지스틱 회귀, 히스토그램 그래디언트 부스팅, 랜덤 포레스트,
시장 국면별 역 Brier 가중 앙상블을 비교한다. 후보가 되려면 다음 조건을 모두
만족해야 한다.

- 최종 시험 정확도가 기준 모델보다 최소 0.20%p 높음
- Brier Score 개선
- ECE가 기준 모델보다 0.002를 초과해 악화되지 않음
- 고신뢰 선택 신호의 비용 차감 평균 수익 개선 및 150회 이상 발생
- 월별 워크포워드 안정성 기준 통과

후보 모델은 자동으로 운영 모델이 되지 않는다. 사용자가 결과를 확인하고 명시적으로
적용해야 하며, 적용과 기준 모델 복원 이력은 별도 저장된다.

## 해석 원칙

전체 방향 적중률이 70% 또는 80%에 도달하지 않았더라도 실패를 숨기지 않는다.
성과가 개선되지 않으면 후보는 거절 상태로 남기고, 어떤 구간에서 약한지와
고신뢰 신호를 얼마나 자주 낼 수 있는지를 함께 표시한다. 이 프로그램의 결과는
수익을 보장하지 않으며 투자 판단의 참고 자료다.
