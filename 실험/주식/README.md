# Stock Insight

무료 데이터 기반의 로컬 주식 분석 대시보드입니다. 한국·미국 종목의 가격, 캔들차트,
뉴스, 재무, DART/SEC 공시, DAY 1·DAY 2 예상, 포트폴리오 평가와 예측 적중률을 함께
확인할 수 있습니다.

## 실행

프로젝트 폴더의 `실행하기.bat`을 더블클릭합니다.

- 웹 화면: http://127.0.0.1:5173
- API 문서: http://127.0.0.1:8010/docs
- 종료: 실행하면서 열린 API와 Web 창을 닫습니다.

## 주요 기능

- 원하는 종목 추가, 태그·메모·검색
- 대시보드 카드 숨김과 복원
- 일봉 및 1분봉 캔들차트, 확대·이동·전체화면, 이동평균·거래량 선택
- DAY 1·DAY 2 예상 범위와 상승·하락 가능성
- 데이터 품질이 낮을 때 자동 `판단 보류`
- 뉴스 중복 제거, 감성 분석, 원문 링크
- yfinance 재무 지표, 무료 DART·SEC 공시
- 국내·해외 TOP5와 `급등 주의` 표시
- 급등 종목은 TOP5에서 제외하지 않음
- 백그라운드 분석 진행률, 중단, 실패 내역
- 과거 예측 적중률과 평균 절대오차
- 포트폴리오 평가손익·종목 비중·집중 위험
- 예약 분석, 디스코드·텔레그램·이메일 알림
- CSV 내보내기와 브라우저 PDF 인쇄
- SQLite 백업·복원·보존 기간 정리

## 무료 데이터의 한계

- 1분봉은 거래소 공식 실시간 체결 데이터가 아니며 15~20분 이상 지연될 수 있습니다.
- 무료 제공처의 호출 제한이나 장 운영 상태에 따라 가격·뉴스·재무가 누락될 수 있습니다.
- TOP5는 무료로 수집 가능한 후보군과 사용자가 추가한 종목을 비교합니다. 유료 전 종목
  실시간 스크리너와 동일하지 않습니다.
- DAY 1·DAY 2 값은 규칙 기반 추정치이며 수익을 보장하지 않습니다. 예측 검증 화면의
  표본 수와 실제 적중률을 먼저 확인하세요.

## DART 설정

1. Open DART에서 무료 API 키를 발급받습니다.
2. 앱의 `자동화·설정`에서 DART API 키를 저장합니다.
3. 한국 종목 상세 화면에서 최근 공시를 확인합니다.

미국 SEC 공시는 별도 API 키 없이 조회합니다.

## 알림 설정

`자동화·설정`에서 목표 수익률, 손실 기준과 디스코드 웹훅 또는 텔레그램 봇 정보를
입력합니다. 프로그램이 실행 중일 때 예약 분석 이후 알림 조건을 점검합니다.

## 수동 개발 실행

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

```powershell
cd frontend
npm.cmd run dev -- --host 127.0.0.1
```

## 검증

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

```powershell
cd frontend
npm.cmd run build
```
